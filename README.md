# «Продолжить с пересказом» — прототип доработки VK Видео

Концепт для тестового задания на стажировку VK «Менеджер продукта». Не официальный продукт VK.
Что и зачем делаем — в [SPEC.md](SPEC.md). Этот файл — о том, как устроен прототип.

## Запуск

Сборки и зависимостей нет — это статичные файлы. Из папки проекта:

```bash
python3 -m http.server 8124
```

и открыть http://localhost:8124. Подойдёт любой статический хостинг (GitHub Pages, Vercel).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка всех экранов, панель проверяющего, SVG-иконки (`<symbol>`), подключение стилей и скриптов |
| `styles.css` | Все стили. Токены VKUI — в начале файла, светлая тема — отдельным блоком. **Порядок блоков важен** (поздние уточняют ранние) — карта блоков в шапке файла |
| `app.js` | Вся логика: экраны, плеер, плашка, шторки, правила показа, аналитика, демо. Карта разделов и граница «продукт / демо» — в шапке файла |
| `data.js` | Данные: видео, главы, пересказы, полки `continueList`, `history`, `later` (`window.DATA`) |
| `fx.js` | Только демо: фон с искрами на canvas |
| `media/` | Стоковые ролики и обложки Mixkit, аватары, логотип; источники — `media/CREDITS.md` |

## Что переносить в продукт, а что нет

**Продукт** (описан в SPEC.md, разделы 5–6, 9):
- полка «Продолжить просмотр» и метка «✦ Есть пересказ» (5.1);
- плашка «Что было до X»: видео не ждёт, таймер 8 с с паузой при наведении/касании, сворачивание в кнопку ✦ (5.2);
- шторка «Что было раньше» (5.3) и кнопка ✦ в ряду действий (5.4);
- правила показа: порог 24 ч, выключение автопоказа после 2 пропусков подряд на любых видео, возврат после ручного открытия, видео без речи, ошибка загрузки (раздел 6);
- события аналитики — функция `track()`, названия и параметры как в SPEC.md, раздел 9.

Входы этапа 2 — блок в «Описании» и вкладка «✦ Пересказ» в панели глав — в коде есть, но выключены флагом `STAGE2` в `app.js`.

**Только демонстрация** (в продукт не переносится): панель проверяющего, сценарии и пошаговый демо-курсор (`runTour`, `runGhostDemo`, `STEPS`), окошко шагов, переключатели версии и темы, телефон-рамка и её масштаб, подсветка рабочих зон при нажатии мимо, фон `fx.js`, служебные события `tour_start`, `version_switch`, `theme_switch`, `demo_next`, `demo_cursor_click`.

## Как поменять данные

- **Пересказ видео** — массив `recap` у видео в `data.js`: `{ t, title, text }`, где `t` — секунда начала главы. В пересказ попадают только главы до `stoppedAt` (без спойлеров).
- **Главы** — массив `chapters`: `{ t, title }`.
- **Место остановки** — `stoppedAt` (секунды); длительность — `duration`.
- **Порядок полки** — `continueList` (сейчас подкаст про продуктовые метрики стоит в центре).

## Ключевые константы (`app.js`)

| Константа | Значение | Смысл |
|---|---|---|
| `PEEK_MS` | 8000 | сколько плашка висит под плеером |
| `SKIP_LIMIT` | 2 | сколько пропусков подряд выключают автопоказ |
| `GAP` | 72 / 2 ч | «сколько прошло с прошлого просмотра» в сценариях (порог — 24 ч) |
| `STAGE2` | `false` | включить входы этапа 2 |

## Ограничения прототипа

- Видео — короткие стоковые ролики по кругу; время в плеере условное.
- Пересказы написаны вручную как образец ответа модели; генерация описана в SPEC.md, раздел 7.
- Код — демонстрационный: один файл скриптов и один файл стилей без сборки. Для разработки опираться на SPEC.md (тексты, состояния, правила, события, токены), а не переносить код как есть.
